# Contributing

Thank you for helping keep this list useful. Anyone can add, correct or remove an entry, including providers listing their own product.

## What belongs here

- Perfume and fragrance APIs, MCP servers, datasets and developer tools that are public and working.
- Projects with a public page or repository that a developer can reach today.

## Entry format

```
- [Name](https://link) - What it is (type); how you access it and what it costs; what it covers; one more fact if useful.
```

- One line, one sentence-style description. State auth (none, key, OAuth), free tier or price, and type (REST, MCP, file, wrapper).
- Numbers: use the provider's own figures and mark them "claimed", or count them yourself and say so. Say "unofficial" for anything scraped or built on another site's pages.
- No superlatives (largest, fastest, first, only, best), no marketing adjectives, no affiliate links.
- Keep the alphabetical order of the section. A product with both a REST API and an MCP server goes in both sections.
- If you list your own product, say so in the pull request. It is held to the same rules.

## Pull request checklist

- [ ] The link works and the product is publicly reachable.
- [ ] The description is factual and matches the provider's public docs.
- [ ] Entry is in the right section and in alphabetical order.
- [ ] Source of any numbers is clear.

## Corrections and removals

Open an issue or pull request with the public page that shows the change. Entries for projects that are gone, or that no longer match their description, are removed.

By contributing you agree that your contribution is released under CC0.
